# design-system

## When to use
Use when the user requests work aligned with this skill. Confirm scope and inspect the repository before editing.

## Workflow
1. Audit existing tokens and components.
2. define semantic color, type scale, spacing, radii, elevation and motion.
3. implement reusable components and state variants.
4. document usage and migration.
5. avoid duplicate tokens.

## Deliverables
Provide token inventory, component examples, contrast checks and adoption plan.

## Quality gates
- Preserve existing behavior unless explicitly approved.
- Do not claim tests passed unless actually executed.
- Never expose secrets or modify production without approval.
- Record limitations, risks, and verification evidence.
