# frontend-design

## When to use
Use when the user requests work aligned with this skill. Confirm scope and inspect the repository before editing.

## Workflow
1. Inspect existing layout, tokens, and product goals.
2. propose hierarchy, typography, spacing, and states.
3. implement mobile-first.
4. use restrained motion with reduced-motion fallback.
5. test keyboard, contrast, and responsiveness.

## Deliverables
Provide changed components, screenshots or visual review notes, accessibility findings, and commands run.

## Quality gates
- Preserve existing behavior unless explicitly approved.
- Do not claim tests passed unless actually executed.
- Never expose secrets or modify production without approval.
- Record limitations, risks, and verification evidence.
