# fullstack-development

## When to use
Use when the user requests work aligned with this skill. Confirm scope and inspect the repository before editing.

## Workflow
1. Trace user flow and contracts.
2. design typed input/output.
3. validate server-side.
4. implement authentication and authorization.
5. handle errors and loading.
6. write migrations if needed.
7. add tests.
8. avoid breaking existing APIs.

## Deliverables
Provide implementation summary, contract changes, tests, and rollback notes.

## Quality gates
- Preserve existing behavior unless explicitly approved.
- Do not claim tests passed unless actually executed.
- Never expose secrets or modify production without approval.
- Record limitations, risks, and verification evidence.
